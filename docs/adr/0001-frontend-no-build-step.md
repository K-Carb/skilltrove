# ADR-0001：前端零依赖、无构建链

状态：已采纳（2026-08）

## 背景

看板前端需要持续快速迭代，目标用户在本地 Windows 环境运行，团队没有专职前端。

## 决策

原生 JS + CSS 变量，禁止 npm/打包器/CDN。`app.js` 以普通 `<script>` 加载（非 ES module）。

## 后果

- 好处：clone 即跑、无供应链面、无构建产物、缓存问题少（静态资源 no-cache）
- 代价：单文件 `app.js` 体量已超 1000 行，模块化只能靠注释分区
- 再评估触发点：若需要引入图表库或 `app.js` 超过 ~2000 行，改用原生 ES module（`type="module"`）拆分——不需要引入构建链
