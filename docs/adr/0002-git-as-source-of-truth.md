# ADR-0002：共享技能库以 git 为唯一事实源

状态：已采纳（2026-08）

## 背景

技能库需要多人同步、审计与回滚，但不引入服务端数据库。

## 决策

- `registry/registry.json` + `skills/` 目录即数据库，git 提交即入库
- 运行时可变产物（`data/`、`archive/`、日志）不入库或单独治理
- 审核动作直接写 registry，由使用者提交 git 同步给团队

## 后果

- 好处：零服务端、天然审计与回滚、离线可用
- 代价：无并发写保护（本地单用户假设）；"发布后请提交 git"成为人工纪律（看板文案已提示）
