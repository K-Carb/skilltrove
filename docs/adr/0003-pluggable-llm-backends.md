# ADR-0003：LLM 后端可插拔，默认本机 CLI

状态：已采纳（2026-08）

## 背景

聚类复核与技能起草需要 LLM；不同团队的可用后端不同（本机 CLI / 本地网关 / 云 API），且不想把密钥写进仓库。

## 决策

`cli/llm.py` 统一入口，`LLM_BACKEND` 环境变量切换（kimi / claude / codex / openai-compatible）；密钥只走环境变量。

## 后果

- 好处：无厂商锁定、密钥不入库、可降级（无 LLM 时看板仍可用，仅发现/起草不可用）
- 代价：各后端输出解析分散在 llm.py；新增后端需改代码（当前可接受）
